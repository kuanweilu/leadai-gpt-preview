Ask, Use, Manage, Build aren't just four dimensions. Each one has three levels of depth (Basic / Proficient / Advanced) and three literacy types (Knowledge / Skill / Attitude). This isn't taxonomy — it's the coordinate system that determines how far you can go in the AI era.
